# Muhammad Omair — Portfolio

Personal site. Next.js, TypeScript, Tailwind, Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

Resume PDF is generated from `scripts/resume.html`:

```bash
npm run resume
```

Project screenshots (optional, needs live URLs):

```bash
npm run screenshots
```

Drop UI shots into `public/images/projects/<id>/1.png` … `4.png`.
